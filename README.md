# Airbnb Clone

A modern Airbnb clone built with Node.js, Tailwind CSS, MongoDB, NextAuth.

## Live Demo

https://airbnb-clone-lac-ten.vercel.app

## Features

- Responsive and modern UI
- Property listing and browsing
- Search and filter functionality
- User authentication
- Booking system
- Interactive maps
- Favorite and reservation management
- Mobile-friendly design

## Tech Stack

- Node.js
- React
- TypeScript
- Tailwind CSS
- MongoDB
- NextAuth

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm or yarn

### Installation

```bash
git clone https://github.com/Rishav-2310/Airbnb-clone.git
cd <project-folder>
npm install
```

### Run Locally

```bash
npm run start
```

Open http://localhost:3000 or http://localhost:3001 in your browser.

## Build

```bash
npm run build
```

## Start Production Server

```bash
npm run start
